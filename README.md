# 上岸 · 公考备考工作台

个人备考工作台（纯前端单页应用，数据保存在浏览器 localStorage）。

## 在线访问

开启 GitHub Pages 后访问：`https://<你的用户名>.github.io/<仓库名>/`

## 功能

- 📚 考试倒计时（国考 / 省考 / 事业编）
- ✅ 每日必做 + 我的任务清单 + 自制定学习计划（可划线勾选）
- 📖 七大科目刷题记录与正确率（言语理解 / 判断推理 / 数量关系 / 资料分析 / 常识判断 / 申论 / 综应）
- 📅 打卡日历（滚轴选择学习时长）
- 📕 错题本（拍照 + 语音输入）
- 📈 学习时长折线图（按日 / 周 / 月 / 年）
- 🍅 番茄猫游戏化专注钟（像素猫进化 + EXP 等级）
- ⚙️ 个性化设置（工作台名称 / 头像 / 5 套颜色主题）

## 页面

| 文件 | 说明 |
|---|---|
| `index.html` | 主工作台（含番茄钟模块） |
| `tomato-cat.html` | 番茄猫专注钟独立版 |

## 数据说明

所有数据仅保存在你自己的浏览器中，不会上传服务器。换设备或清除浏览器数据前，请在「设置 → 数据管理」导出备份。
